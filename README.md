🎮 Jogo da Velha Moderno
Um jogo clássico da velha desenvolvido com foco em uma interface de usuário (UI) moderna, limpa e responsiva. O projeto inclui um sistema de placar acumulativo e lógica de vitória/empate em tempo real.

🚀 Tecnologias Utilizadas
HTML5: Estruturação semântica do tabuleiro e elementos de interface.

CSS3: Estilização avançada utilizando:

Variáveis CSS (:root) para fácil manutenção de cores.

Glassmorphism: Efeito de vidro translúcido no container principal.

Flexbox e Grid: Para um layout perfeitamente alinhado e responsivo.

Animações de hover e transições suaves.

JavaScript (ES6+):

Manipulação do DOM.

Lógica de verificação de vitória baseada em matrizes de combinação.

Sistema de pontuação automática até 10 pontos.

🕹️ Funcionalidades
Placar Dinâmico: Acompanha as vitórias dos jogadores X e O durante a sessão.

Reset Automático: Após uma vitória ou empate, o tabuleiro limpa sozinho após 1.5 segundos para manter o fluxo do jogo.

Condição de Vitória: O primeiro jogador a atingir 10 pontos é coroado o grande campeão com um alerta especial.

Feedback Visual: Cores distintas para X e O, além de uma mensagem indicando de quem é a vez.
